# ROUTING_TAXONOMY_CORPUS_V1

Corpus state: **NOT FROZEN / NEEDS_MORE_DATA**.

The corpus is an external governed collection; source control contains only contracts, templates, and reports. A freeze is allowed only after asset integrity, PHI, usage, lineage, review, adjudication, coverage, concentration, and leakage gates pass. A freeze records corpus/truth/source/review/leakage/qualification hashes together with the frozen hierarchical baseline Git SHA and bundle hash, taxonomy version, verifier policy versions, processing-route contract version, and corpus-builder version.

An existing `FROZEN` record is immutable. Excluded assets may remain in the intake audit but cannot contribute to corpus hashes or metrics. Pending assets block freeze.
