# Phase 7A.12 Review Agreement

Double-reviewed pages: **0**. Agreement and Cohen’s kappa are **not measured**.

Reviewer tasks expose an asset ID but no existing label. A reviewer must attest that other reviews were hidden. CMS/UB confusers are always double-reviewed; a stable blinded sample supplies additional review coverage. Top-level, standard/non-standard, CMS/UB, subtype, route, or ambiguity disagreements require adjudication. Free-text review comments are not accepted; ambiguity uses controlled reason codes.
