# Routing Distinguishability Audit V2

Status: **PENDING INDEPENDENT HUMAN REVIEW**.

Each selected hard pair must be reviewed independently at four disclosure levels: thumbnail, full-resolution image, image plus OCR, and image plus bundle context. Required pairs are CMS/custom professional, UB/custom institutional, UB/itemized bill, UB/hospital invoice, custom structured/EOB, and claim/claim-support.

The audit records reviewer decisions, minimum sufficient disclosure level, ambiguity, and expected processing route. If reviewers cannot reliably distinguish two subtypes and both share the same safe route, the result is `TAXONOMY_COLLAPSE_RECOMMENDED`. No automated prediction is represented as human distinguishability evidence.
