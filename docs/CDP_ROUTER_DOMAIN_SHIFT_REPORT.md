# Router Domain Shift Report

Generated numerically by `evaluation/router_domain_shift_analysis.py`. The
machine-readable report compares means, medians, P10/P90, zero frequencies,
absolute/relative deltas and standardized effects for every persisted V3
score, structure and geometry feature. The representative source is diagnostic
only and prohibited for Router V4 calibration.

The audit must be regenerated after any observation-schema change; numbers are
not copied manually into this document to avoid stale or invented claims.
