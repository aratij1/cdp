# Visual Router False-Standard Forensics

The frozen cross-source baseline produced two CMS-to-UB errors. Both were low-margin outliers: margins were 0.179 and 0.131 versus a 0.914 median for correctly classified UB pages. One error had stronger CMS than UB structural evidence; neither had usable anchor or geometry evidence. The complete immutable audit is in `evaluation_results/router_visual_v1/false_standard_forensics.json`.

This supports testing a contradiction veto, but does not justify granting the visual model route authority.
