# ML router development dataset

`ROUTING_DEV_ML_ELIGIBILITY_V1` contains two source-separated, PHI-safe feature datasets derived only from the independent remediation corpus: 100 PIL/Tahoma pages in Source A and 100 OpenCV-resampled/padded pages in Source B. Each records train, validation, calibration and adversarial partitions. Frozen V4-A/B/C/D were not used.

This is a source-separated view of remediation evidence, not an external corpus. `UNKNOWN_UNSTRUCTURED` is absent, and cross-source evaluation contains only 26–31 pages per direction. These limitations independently block promotion.
