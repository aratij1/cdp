# Visual evidence cross-source results

Two 120-page sources cover all five route families. A and B use distinct PIL/Tahoma and OpenCV-resampled/padded pipelines; no frozen V4-A/B/C/D page was used.

The visual-only classifier achieved 99.17% accuracy in both directions. Worst-source recall was CMS 96.67%, UB 100%, structured 100%, unstructured 100%, and non-claim 100%. Each direction nevertheless produced one CMS→UB error: false-standard eligibility was 0.83%, exceeding the 0.5% gate.

The sources still share remediation layout assumptions and no third independent source exists, so this is not sufficient evidence of production generalization.
