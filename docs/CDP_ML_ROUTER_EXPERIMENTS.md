# ML router experiments

ML-01 trained governed LightGBM multiclass artifacts on each development source. ML-02 measured LightGBM as eligibility evidence with calibrated thresholds and deterministic corroboration. ML-03 compared XGBoost. ML-04 applied family-specific fusion without changing final scoring.

Result: `REJECT`. Worst-source CMS eligibility was 20%, UB 80%, structured 14.29%, and non-claim 0%. Final deterministic routing did not improve, although false standard routes remained zero and LightGBM inference was sub-millisecond. Frozen A/B/C/D were not rerun; candidate, holdout, shadow and Phase 7B remain blocked.
